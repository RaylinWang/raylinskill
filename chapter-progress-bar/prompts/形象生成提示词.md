# 形象生成提示词

用户还没有自己的形象图时，Agent 把下面对应的**一段**发给用户（整段放进一个代码块，方便一键复制）。用户把它和一张自己的正面照一起发给任意 AI 生图工具（即梦、豆包、可灵、ChatGPT、Midjourney 等），生成好以后回来上传。

两段都不用改：发型、发色、配饰都从用户的照片里取。

---

## D 真人表情头像

```
请以我上传的照片为唯一身份参考，生成 3 张同一个人的大头贴纸头像，每张一个表情，分开出图：
1. 自然微笑：正视镜头，嘴角轻轻上扬，放松温柔
2. 俏皮眨眼：一只眼睛自然眨起，另一只正视镜头，嘴角带自信浅笑
3. 可爱嘟嘴：嘴唇轻轻向前噘起，眼神灵动，脸颊微微鼓起

3 张都要满足：
- 高度还原照片里的本人：脸型、眼型、眉眼间距、鼻梁和鼻头、嘴唇轮廓、下巴线条、五官比例都不变；不要幼化成小孩，不要变成陌生人
- 发型、发色、配饰（眼镜、耳环、发饰、帽子等）和照片保持一致
- 只保留头部到脖子，不要身体、衣服和原来的背景
- 纯白背景，正脸，头部居中，四周留白；3 张的大小、角度、光线一致
- 写实人像摄影质感，柔和均匀的光线，皮肤保留自然质感，不要过度磨皮，不要卡通化
- 边缘干净利落，有头像贴纸的感觉；不要文字，不要水印，不要边框
- 高清，每张单独一张图，不要拼在同一张图里
```

## C 手绘走路小人

```
请以我上传的照片为身份参考，把我画成一个黑白极简手绘 Q 版小人，生成 4 张同一个小人走路的不同姿势，每张一个姿势，分开出图：
1. 开心赶路：向前迈步，一只脚迈出，手臂自然前后摆动，开心张嘴笑
2. 插兜大步走：一只手插兜，另一只手轻轻摆动，嘴角微扬，眼神淡定
3. 轻快小跑：双脚一前一后，双臂向两侧轻轻张开，眯眼大笑
4. 悠闲慢走：小步散步，手臂垂在身侧，表情平静放空

4 张都要满足：
- 极简手绘简笔画风格：圆润的白色圆脸，黑色粗细均匀的单线轮廓，点状豆豆眼，弧线小嘴，淡淡腮红；头大身小，四肢短小，比例可爱质朴
- 从照片里提取能认出我的特征：发型、发色、眼镜 / 帽子 / 发饰等配饰；除了头发的颜色，人物、衣服、身体全部只用黑白两色
- 4 张必须是同一个小人：脸、发型、衣服、线条粗细、大小都一致，只有姿势和表情不同
- 全身入画，4 张都侧身朝画面右边走
- 纯白背景，人物居中，四周留白；最多在旁边加一两笔黑色短线，不要其他装饰
- 线条干净、简单、稚拙；不要文字，不要水印，不要阴影，不要厚涂，不要画成精致的商业漫画脸
- 高清，每张单独一张图，不要拼在同一张图里
```

---

**工具一次只能出一张时**：先发整段生成第 1 张，再接着说「同一个人物，换成第 2 个」，依次生成。
